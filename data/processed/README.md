## Contains the following files:

1. vocab.txt - Vocabulary of 50000 words processed using the corpus jsonl files defined in /data/raw folder in the format <word, count> curated from https://convokit.cornell.edu/documentation/subreddit.html 

2. vectors_imbued.txt: Trained GloVe embeddings

3. trainingdata.csv: Classification Training Data: https://www.kaggle.com/datasets/footsurebead/mental-status 

4. concepts.txt: concept words
